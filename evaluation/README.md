# SuperMew RAG 检索评估

本目录用于比较不同检索策略，不直接修改线上问答流程。

## 评估集设计

`dataset.jsonl` 每行是一条人工检查过的问题，包含：

- `relevant_pages`：标准相关页码，用于计算页级命中；
- `relevant_keywords`：用于辅助检查返回文本是否覆盖核心事实。

当前评估集包含 30 条问题，覆盖定义理解、数字事实、时间事实、列表归纳、供应链、门店运营、数字化和跨页问题等场景。

## 指标

- Hit Rate@K：前 K 个结果是否命中相关页；
- MRR：第一个相关结果排名的倒数平均值；
- Keyword Coverage：相关关键词在 Top-K 文本中的覆盖比例。

> 页码是根据 PDF 阅读页码记录的。若后续重新导入文档时使用 0-based page metadata，需要在评估脚本中统一转换。
